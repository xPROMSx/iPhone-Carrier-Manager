# Сообщения об уязвимостях

Не публикуйте эксплуатационные подробности до исправления: ими могут воспользоваться
для причинения вреда пользователям. Не прикладывайте реальные идентификаторы устройств
или секреты.

Когда в репозитории доступна приватная отправка, откройте вкладку **Security**,
затем **Report a vulnerability**. Опишите проблему, условия воспроизведения
и возможные последствия с выдуманными данными.

Если кнопки нет, не создавайте публичное issue с эксплуатационными подробностями.
Попросите владельца через issue включить приватную отправку, не раскрывая саму уязвимость.
