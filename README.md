# iPhone-Carrier-Manager

v0.2: чтение ранее сопряжённого iPhone по USB, проверка и подготовка IPCC
в памяти, установка на одну явно выбранную линию с перезагрузкой и проверкой чтением.

## Состояние разработки

Реализация v0.2 требует проверки владельцем на Windows 11 и реальном устройстве.
Прочитанная схема наблюдалась только на одном iPhone 17 Pro с iOS 27.2.1.
Смысл Slot и полнота списка eSIM не доказаны. Другие устройства и iOS не заявлены
поддерживаемыми. Криптографическая проверка не реализована; подпись всегда UNVERIFIED.

## Возможности

- `info`: сведения устройства и доступные операторские записи.
- `check`: ZIP/plist, метаданные, обнаружение файлов подписи и SHA-256 исходника.
- `build`: пробное переименование внешнего bundle в памяти с побайтовым сравнением файлов.
- `install`: одна установка, одна перезагрузка и проверка профилей чтением телефона.

Нет экспорта пакета, удаления профилей, автоповторов установки и перезагрузки,
каталога операторов, загрузки IPCC,
истории, GUI, телеметрии, сервера и автообновлений.

## Требования

Windows 11 x64. Windows 10 не проверена. Для Python-пакета: Python >=3.12;
разработка и CI используют 3.12. Для EXE отдельный Python не нужен.

Для USB нужны работающие компоненты Apple из iTunes или Apple Devices.
На части компьютеров USB обслуживает AppleMobileDeviceProcess; службы с названием
Apple Mobile Device Service может не быть, и её отсутствие само по себе не ошибка.
Документация библиотеки:
https://doronz88.github.io/pymobiledevice3/master/installation/
Программа не устанавливает
драйверы, не меняет и не запускает службы, не требует администратора автоматически.
Нужны USB-кабель, разблокированный телефон и существующее сопряжение.
При отсутствии доверия выполните его штатно вне программы, затем повторите команду.

## Установка

Переносимая сборка: распакуйте весь приватный ZIP в папку и запускайте
`iphone-carrier-manager.exe`. Соседние файлы и `_internal` необходимы.
Артефакт создаёт владелец меткой `build-windows` в Draft PR, хранение 7 дней.
Новый коммит автоматически не пересобирает EXE; проверьте SHA артефакта.

Python-пакет из checkout: `python -m pip install .`.
Команды доступны также через `python -m iphone_carrier_manager`.
Разработка: [CONTRIBUTING.md](CONTRIBUTING.md).

## Использование

`--help` описывает аргументы, `--version` показывает версию. Ctrl+C прекращает команду.

```text
iphone-carrier-manager info
iphone-carrier-manager check source.ipcc
iphone-carrier-manager check local-packages
iphone-carrier-manager build --source source.ipcc --line slot:kOne
```

`info` требует USB и читает lockdown. Получает полный GetValue внутри библиотеки,
но показывает только разрешённые сведения. Сырые ответы не сохраняются и не логируются.
Активность линий не определяется. При недостатке данных выводится «линия не определена».
Полнота списка не гарантируется. Ничего на телефоне не изменяется. Остановка: Ctrl+C.

`check` не требует телефона и не меняет исходник. Проверяет один файл или непосредственно
лежащие в каталоге IPCC, без рекурсии. Результаты печатаются по порядковым номерам, имя исходного файла не выводится,
отчёт не сохраняется.
SHA-256 относится к исходному файлу и не доказывает подлинность Apple. Остановка: Ctrl+C.

`build` требует USB и один явно заданный IPCC. Селектор сравнивает строку Slot точно:
`slot:kOne` не означает «SIM 1» или включённую линию. Используются длинные ключи
`InternationalMobileSubscriberIdentity` и `IntegratedCircuitCardIdentity` из того же элемента.
MNC остаётся строкой с ведущим нулём. Числовой или повторяющийся Slot вызывает отказ.
Текущий профиль и его точная версия обязательны. Целевой профиль может отличаться;
оба профиля выводятся для сравнения без обещания совместимости.

Идентификаторы: строго строки ASCII-цифр, абонентский 10–15, SIM 18–22 символа.
Нормализации нет. После свежего чтения проверяется неизменность выбранной записи.
Пакет пересобирается в BytesIO, внутренние файлы сравниваются побайтно.
Результат и идентификаторы на диск не сохраняются. Маска содержит только длины:
«абонентский идентификатор: 15 цифр, идентификатор SIM: 19 цифр».
Полные значения, их фрагменты, полное внешнее имя и хеш подготовленного ZIP не выводятся.
Остановка: Ctrl+C, без продолжения операции.

**Результат не сохраняется, на iPhone не устанавливался. Успех подготовки не означает
совместимость с iOS и пригодность к установке, в том числе после будущей проверки
подписи. Сейчас подпись не подтверждена.**

## Установка профиля на одну линию

**Команда install записывает операторский профиль и перезагружает весь iPhone.**
Она может изменить операторские настройки. Совместимость и полный возврат к прежнему
состоянию не проверены. Программа не удаляет профили. Возврат означает ещё одну
установку прежнего пакета, а не восстановление полного состояния телефона.
Подпись UNVERIFIED: подлинность пакета криптографически не подтверждена.
Не отключайте кабель и не трогайте телефон до конца; после перезагрузки разблокируйте его.

Заранее подготовьте устанавливаемый IPCC и пакет текущего профиля для возврата.
Если у прежнего пакета совпадает идентификатор, но отличается версия, возврат считается
приблизительным. Другой идентификатор запрещает операцию. Повторная установка того же
пакета разрешена. За одну команду выбирается только одна линия, точным значением Slot.

```text
iphone-carrier-manager install --source new.ipcc --line slot:kOne --previous previous.ipcc
```

Перед записью программа проверит оба файла, перечитает телефон в той же сессии,
покажет модель, iOS, выбранную линию, текущий и целевой профили, тип возврата и предупреждения.
При iOS, отличной от 27.2.1, появится дополнительное предупреждение.
Продолжение требует терминала и ввода ровно `INSTALL`, с учётом регистра, без пробелов.
Перенаправленный stdin не подходит. До этого подтверждения записи нет.

Установка вызывается один раз с пределом 120 с. Только ответ Complete разрешает
однократный restart. При отказе службы, обрыве, тайм-ауте или Ctrl+C во время установки
перезагрузки нет; программа один раз попробует прочитать профили.
Результат может остаться неизвестным. Автоматически повторять команду нельзя считать
безопасным продолжением: сначала прочитайте `info` и проверьте телефон.

Отключение USB ожидается до 60 с, затем возврат и чтение вместе до 300 с.
Опрос выполняется раз в секунду, ошибка списка не считается отключением.
При запросе кода программа напоминает разблокировать iPhone. Если отключение не замечено,
чтение всё равно выполняется, но результат остаётся неподтверждённым.
Ctrl+C после начала установки даёт неподтверждённый результат и не отменяет уже сделанную запись.

`ПОДТВЕРЖДЕНО (перезагрузка подтверждена косвенно)` и код 0 требуют всех условий:
Complete, успешного restart, наблюдаемого отсутствия USB, возврата того же телефона,
точного идентификатора и версии целевого профиля, неизменного состава и остальных линий.
Ошибки закрытия соединений после успешного restart не отменяют его успех.
Совпадение профиля без этих условий, в том числе при повторной установке, недостаточно.
`НЕ ПОДТВЕРЖДЕНО` с причиной и кодом 4 означает недостаток подтверждения, а не доказанный провал.
После ошибки restart перезагрузите телефон вручную и выполните `info`.

Для возврата самостоятельно повторно установите прежний пакет, поменяв файлы местами:

```text
iphone-carrier-manager install --source previous.ipcc --line slot:kOne --previous new.ipcc
```

Эта операция тоже требует проверок и подтверждения, тоже не гарантирует полный возврат.
Если фактически прочитанный текущий профиль не соответствует пакету `--previous`,
проверка не пропустит команду. Не обходите её; сначала проверьте состояние телефона.

## Что программа меняет на телефоне

`info`, `check`, `build` не меняют настроек, профилей, файлов или доверия.
`install` через AFC передаёт распакованный пакет в `/PublicStaging/pymobiledevice3/<uuid>.ipcc`,
вызывает службу установки CarrierBundle и Diagnostics restart. Библиотека пробует удалить
временный каталог нерекурсивно, без проверки результата: файлы с идентификаторами могут
остаться на телефоне. Программа не очищает PublicStaging.
Используется существующее сопряжение, автосопряжение отключено. Wi-Fi и туннелей нет.

На компьютере библиотека читает существующие pairing records: usbmuxd, системный Apple
Lockdown, затем локальный каталог. Если `~/.pymobiledevice3` отсутствует, используется
временный каталог операции, удаляемый после неё. Он живёт до финального чтения после
перезагрузки; повторные подключения используют тот же источник. Новых записей доверия
программа не создаёт. Подготовленный ZIP и полные идентификаторы на диск компьютера не пишутся.

Штатный TLS может временно записать существующие сертификат и приватный ключ хоста
в системный temp. Библиотека удаляет файл в finally, но запись происходит до try:
после ошибки записи, аварии или отключения питания очистка не гарантируется.
Физическое уничтожение памяти, swap, crash dump и копий файлов не обещается.
При отмене до возврата фабрики её внутреннее соединение может оставаться до выхода
процесса; ОС закрывает его при выходе. Повторов установки/restart нет; после restart
повторяются только опросы и чтение. Тайм-ауты: usbmux 5 с,
подключение и чтение суммарно 15 с; библиотечное переподключение остаётся внутри ожидания.

## Безопасность и ограничения

В v0.2 подпись всегда `UNVERIFIED`: правила подписываемых данных и происхождение ключа
не подтверждены. Наличие signatures не доказывает подлинность; отсутствие указано отдельно.
`VERIFIED` означал бы полную математическую проверку доверенным ключом, но не совместимость
установки. `INVALID` относится к неуспешной поддерживаемой криптографической проверке;
в v0.2 она не реализована. Неподдерживаемый формат отличается от повреждённого ZIP/plist.

Коды: 0 — успех (build только пробный; install подтверждён чтением),
1 — повреждение, ошибка устройства/данных или отмена до установки,
2 — аргументы, 3 — неполная проверка check или неподдерживаемый формат,
4 — результат после начала install не подтверждён.
Неизвестная структура и несколько bundle дают 3 в check и build.
Корректный check с UNVERIFIED даёт 3; успешный пробный build с UNVERIFIED даёт 0.
Любой повреждённый пакет в каталоге исключает общий успех.

Лимиты: 64 MiB исходник, 64 MiB суммарно после распаковки, 10 000 записей.
Все файлы *.plist внутри bundle проверяются на читаемость без интерпретации
дополнительных данных. Stored/Deflate, без извлечения на диск. Проверяются абсолютные пути, сегменты `..`,
обратные разделители, NUL/управляющие символы, дубликаты имён, ссылки/специальные записи,
шифрование и CRC. Проверок имён под файловую систему Windows нет.

Совместимость установки, 5G, VoWiFi и откат не подтверждены. Текущий профиль не считается
заводским. Предупреждения антивируса и Windows 10 не проверены.
