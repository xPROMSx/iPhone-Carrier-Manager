# iPhone-Carrier-Manager

Будущий открытый инструмент для Windows: проверка, подготовка и установка
операторских профилей IPCC на iPhone через USB.

## Состояние разработки

Пока подготовлен только каркас Python-проекта, документация и CI.
Рабочих функций нет. Для взаимодействия с iPhone предусмотрена pymobiledevice3,
но она пока не добавлена в зависимости.

## Возможности

Будут описаны после реализации.

## Требования

Будут уточнены. Целевая платформа: Windows. Для разработки каркаса используется
Python 3.12; локальные команды приведены в [CONTRIBUTING.md](CONTRIBUTING.md).

## Установка

Инструкция появится после первого рабочего релиза.

## Использование

Пока недоступно.

## Что программа меняет на телефоне

Текущий каркас не выполняет операций с телефоном.
Перед появлением рабочих инструкций здесь будут описаны изменяемые данные,
ограничения и возможности восстановления после ошибки.

## Безопасность и ограничения

Установка IPCC может изменить операторский профиль. Полный откат не подтверждён:
повторная установка предыдущего пакета не гарантирует возврат заводского состояния.
Запись на телефон допустима только с явного разрешения владельца и при подготовленном
пути восстановления. Предупреждения будут размещаться перед инструкциями.

Поддержка 5G и VoWiFi, совместимость с версиями iOS не проверены.
Сервер, GUI, телеметрия и автообновления не предусмотрены.
Операторские файлы Apple и реальные данные пользователей в репозитории не хранятся.
О сообщениях об уязвимостях: [SECURITY.md](SECURITY.md).
