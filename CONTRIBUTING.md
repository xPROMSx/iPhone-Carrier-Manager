# Участие в разработке

Предложите изменение через issue или PR в этом репозитории.
Опишите проблему и ожидаемый результат. Небольшие изменения проще проверить
и при необходимости отменить. Правила для ИИ-ассистентов находятся в [AGENTS.md](AGENTS.md).

В тестах разрешены только выдуманные данные и синтетические пакеты,
создаваемые тестами: реальные данные могут раскрыть сведения о владельце устройства.
Операторские файлы Apple добавлять нельзя: этот репозиторий не предназначен
для их распространения.

Для локальной разработки нужен Python 3.12 и Git. Python 3.12 выбран, поскольку
он установлен в среде Codex; предусмотренная архитектурой pymobiledevice3
допускает Python от 3.9. Пока нет необходимости поддерживать более старые версии.
Совместимость каркаса с другими версиями Python не проверена.

Из корня репозитория, в своём виртуальном окружении, выполните:

```sh
python -m pip install -e ".[dev]"
ruff check .
pytest
```

Это установка каркаса для разработки; рабочей программы пока нет.
Изменения также проверяются через CI на Linux и Windows в PR.
Пишите сообщение коммита так, чтобы было понятно, что изменилось и зачем.
Например: «Добавить проверку обязательных шаблонов .gitignore».
